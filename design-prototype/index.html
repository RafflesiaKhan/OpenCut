02

A familiar editor, with room to grow

Left · Materials

Assets and extension tabs. Search or generate, preview a result, then add it to Assets or the timeline at the playhead.

Centre · Preview + timeline

Keep the video and the edit visible. A click on a clip connects the preview, its properties and the Director's context.

Right · Properties / Director

Open chat from the floating icon in the preview. Expand the same conversation into this panel; Draft and Scenes show its working materials.

Try it in the editor

Import loads a sample asset. Select the mock clip to inspect it. Open Director to explore a proposal, apply it and undo it. Reset restores the empty screenshot state. These controls simulate an experience; they do not change a real project.

What the Director knows

ChannelAudience, tone, formats and channel guidelines.
SeriesRecurring characters, episode history and continuity.
Project / episodeCurrent brief, script, assets and timeline.
Brand Kit · selected for this projectFonts, palette, captions, voices, music and visual references. Override a default for one episode.

Small milestones, each with a visible result

The detailed research plan has 14 engineering phases. This view groups them into understandable outcomes. We are at the design step; the order below is a proposal to review.

01
Understand & change the edit

Research phases 1–2

02
Make a useful rough cut

Phases 3–6

Transcript-based cuts, measured caption timing, footage analysis and a clear voice/music mix.

03
Produce a complete episode

Phases 7–9 + core extensions

Branded graphics, narration, shot planning, reusable assets and a reference recipe.

04
Adapt for short-form

Phases 10–12

Find moments, reframe manually first, add short-form captions and export a vertical version.

05
Package, publish & learn

Phases 13–14 · later

Titles, thumbnails and chapters; optional publishing connectors; save lessons for the next episode.

Suggested first walkthrough: choose a clay-style series → agree on an episode idea → write a short script → make narration → add one shot and one sound → review and export.

06

Decisions to make together

Direction already recorded
Classic is the editor base

The fork's working branch is my-suitable-editor; upstream main stays a reference.

Personal tool first; YouTube first

Reuse existing generators and separate local services. Plan a later short-form track.

One editor, connected tools

HyperFrames supplies rendered graphics; the Director coordinates tools and skills. The research plan records Vercel AI SDK as the intended agent loop.

Design questions still open
Where does Director live?

Floating chat and expandable side panel are selected. Refine their size and the visibility of draft and scene materials.

How should a project begin?

Choose channel / series / kit first, or begin with a blank editor and select context later?

What should the left rail contain?

A tab per extension, or a few grouped tabs: Assets, Create, Libraries, Brand Kit?

What is the first complete workflow?

Create a clay episode from an idea, or rough-cut an existing recording? This choice sets the first implementation milestone.

Feasibility still to prove

Reliable word timestamps on longer recordings; media hand-off between browser storage and local services; background generation and import retries; music and GIF sources; project persistence; automated vertical reframing; and optional publishing. These need focused checks before we treat them as finished capabilities.
